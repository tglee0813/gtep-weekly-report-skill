# GTEP 주간업무보고서 스킬 (gtep-weekly-report)

GTEP 요원이 협력업체별로 매주 쓰는 **주간업무보고서**를 AI가 대신 채워주는 스킬입니다.
일주일 동안 업체와 일한 자료(카톡 캡처, 주고받은 파일, To-Do 시트 링크)를 첨부하면, 내용을 파악해 보고서 각 항목을 작성합니다.

Claude와 Codex에서 모두 쓸 수 있습니다.

## 설치 방법

쓰고 있는 AI(Claude 또는 Codex) 입력창에 아래 두 줄을 그대로 붙여넣으면 됩니다.

```
https://github.com/tglee0813/gtep-weekly-report-skill
이 링크의 스킬을 설치해줘
```

AI가 이 페이지를 읽고 자기 환경에 맞게 설치합니다. 저장 버튼이나 허용 창이 뜨면 눌러 주세요.

## 사용 방법

"주간업무보고서 써줘" 또는 "주업보 작성"이라고 하면서 아래 자료를 첨부합니다.

| 자료 | 쓰임 |
|---|---|
| 업체 톡방 캡처 (이번 주 분량) | 업체와의 논의·요청·회신 |
| 동료(공동 담당 요원) 대화 캡처 | 내부 논의, 역할 분담, 계획 |
| 주고받은 파일 (신청서, 보고서, 리스트 등) | 사실 확인, 수치·일정 근거 |
| To-Do / 지원사업 리스트 시트 링크 | 다음주 업무계획, 진행 현황 |
| 주간업무보고서 문서 링크 또는 파일 | 작성 대상 |

구글 문서에 직접 쓰게 하려면 Google Drive·Google Docs 커넥터를 켜 두어야 합니다. 꺼져 있으면 붙여넣을 텍스트로 결과를 줍니다.

## 무엇을 해주나

1. **입력 확인**: 빠진 자료가 있으면 먼저 요청하고, 같은 캡처를 두 번 올렸는지 확인합니다.
2. **자료 읽기**: 세로로 긴 카톡 캡처를 잘라서 확대해 빠짐없이 읽습니다.
3. **선별**: 해당 업체와 관련된 내용만 남기고 잡담·다른 업체 이야기는 뺍니다.
4. **교차검증**: 인증·특허·규격·HS Code·MOU처럼 자료끼리 다를 수 있는 내용을 대조합니다.
5. **항목 작성**: 작성일(항상 그 주 금요일 날짜), 업무기간, C/L 발송 횟수, 정기업무, 전자상거래, 전시회, 주요 논의사항, 다음주 업무계획, 애로사항을 채웁니다.
6. **문서 반영**: 구글 문서에 직접 넣거나, 붙여넣을 텍스트로 줍니다. 각 주차 보고서는 새 페이지 맨 위에서 시작하도록 맞춥니다.
7. **마무리 보고**: 반영한 내용, 고친 내용, 제외한 내용, 확인이 필요한 부분을 정리합니다.

근거가 없는 내용은 쓰지 않고 `확인 필요` 또는 `(추정)`으로 표시합니다.

## 주의

- 캡처에 업체 계정 정보(ID·비밀번호)나 개인 연락처가 보이면 가리고 첨부하세요.
- AI가 쓴 내용은 제출 전에 반드시 직접 검수하세요. 특히 날짜, 수치, HS Code, 인증 표기를 확인하세요.

## AI 에이전트용 설치 지침

사용자가 이 저장소 링크를 주며 스킬 설치를 요청했다면 아래대로 진행합니다.

**스킬 원본 (이 파일 하나가 스킬 전체입니다)**

```
https://raw.githubusercontent.com/tglee0813/gtep-weekly-report-skill/main/gtep-weekly-report/SKILL.md
```

**공통 규칙**

- SKILL.md 내용을 요약하거나 고치지 말고 원문 그대로 저장합니다.
- 스킬 이름(폴더 이름)은 `gtep-weekly-report`로 합니다.
- 같은 이름의 스킬이 이미 있으면 덮어쓰기 전에 사용자에게 확인합니다.

**환경별 설치**

| 환경 | 할 일 |
|---|---|
| Claude 앱 (Cowork·채팅) | 스킬 저장 기능이 있으면 SKILL.md 전체를 담아 저장 카드를 띄웁니다. 그 기능이 없으면 `gtep-weekly-report/SKILL.md` 구조의 zip 파일을 만들어 사용자에게 주고, 설정의 스킬(Skills) 메뉴에 업로드하도록 안내합니다. |
| Claude Code | `~/.claude/skills/gtep-weekly-report/SKILL.md`로 저장합니다. |
| Codex CLI | `~/.codex/skills/gtep-weekly-report/SKILL.md`로 저장합니다. (Windows: `%USERPROFILE%\.codex\skills\gtep-weekly-report\SKILL.md`) |

터미널을 쓸 수 있는 환경의 예시입니다.

```bash
mkdir -p ~/.claude/skills/gtep-weekly-report
curl -fsSL https://raw.githubusercontent.com/tglee0813/gtep-weekly-report-skill/main/gtep-weekly-report/SKILL.md \
  -o ~/.claude/skills/gtep-weekly-report/SKILL.md
```

**설치 후**

저장한 위치를 알려주고, "주간업무보고서 써줘"라고 하며 자료를 첨부하면 된다고 한 줄로 안내합니다. 새 대화에서부터 스킬이 적용될 수 있다는 점도 알려줍니다.
